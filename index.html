ทองไทย (ประมาณจากทองโลก)

บาทละ = ทองโลก (USD/ออนซ์) × ค่าเงินบาท ÷ 31.1035 × 15.244 กรัม × ความบริสุทธิ์ + ส่วนปรับ · เป็นราคาประมาณ ไม่ใช่ราคาประกาศสมาคมค้าทองคำ ปรับส่วนปรับให้ตรงกับราคาร้านที่คุณใช้ได้

ตัวกลางสำหรับหุ้นไทย (ทำครั้งเดียว)

หุ้นไทยไม่มีแหล่งฟรีที่เบราว์เซอร์ดึงตรงได้ จึงต้องมีฟังก์ชันเล็ก ๆ บน Supabase ไปดึงจาก Yahoo Finance ให้ (ราคาหุ้นไทยล่าช้าประมาณ 15 นาที) ใช้กับหุ้นสหรัฐฯ ทองฟิวเจอร์ส และค่าเงินได้ด้วย

  1. Supabase → Edge Functions → Deploy a new function → Via Editor
  2. ตั้งชื่อ ivp-quote วางโค้ดด้านล่าง แล้วกด Deploy
  3. ในหน้าตั้งค่าฟังก์ชัน ปิด Verify JWT (หรือเปิดไว้แล้วใส่ anon key ในช่องคีย์พร็อกซี)
  4. คัดลอก URL ฟังก์ชัน เช่น https://xxxx.supabase.co/functions/v1/ivp-quote มาใส่ช่อง "URL พร็อกซี"
